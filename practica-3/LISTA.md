&#x20;# Lista de Comandos



\*\*pwd\*\*: Muestra la ruta del directorio actual en el que te encuentras.

\*\*ls\*\*: Lista los archivos y carpetas que hay dentro del directorio actual.

\*\*cd\*\*: Cambia de carpeta (por ejemplo, cd carpeta para entrar, cd .. para subir o cd \~ para ir a tu carpeta de usuario).

\*\*mkdir\*\*: Crea una nueva carpeta con el nombre que le indiques.

\*\*touch\*\*: Crea un archivo vacío.

\*\*cp\*\*: Copia un archivo o carpeta de un origen a un destino.

\*\*mv\*\*: Mueve o renombra un archivo o carpeta.

\*\*rm\*\*: Borra un archivo (o una carpeta usando la opción -r).

\*\*cat\*\*: Muestra el contenido de un archivo directamente en la terminal.

\*\*clear\*\*: Limpia la pantalla de la terminal.

\*\*git status\*\*: Muestra el estado actual de tu repositorio y de los archivos.

\*\*git add\*\*: Prepara y añade los archivos modificados para el siguiente guardado.

\*\*git commit\*\*: Guarda oficialmente los cambios en el historial de Git con un mensaje.

\*\*git push\*\*: Sube tus cambios locales al repositorio remoto en GitHub.

\*\*git pull\*\*: Descarga y actualiza los cambios más recientes desde GitHub a tu computadora.
