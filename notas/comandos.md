# Comandos



| Comando | Funcionamiento |
| :---- | :--- |
| git remote add origin <dirección> | Conecta tu repositorio con uno de GitHub |
| git remote -v | Muestra a donde está conectado |
| git push -u origin main | La primera subida: sube y recuerda la pareja |
| git push |Sube tus commits nuevos |
| git pull --no-edit |Lo mismo; sin abrir un editor para el mensaje de la reunión |
| git clone <dirección> | Copia completa de un repositorio, la primera vez |
| git log --oneline --graph | La historia con el dibujo de las uniones |
| Python --versión conde --versión | Comprueban la instalación |
